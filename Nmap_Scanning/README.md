# Ethical Hacking Labs

Hands-on labs from my MCA coursework (Ethical Hacking Lab, Semester III).
All activities were performed **only on my own systems and virtual lab
environment** for educational purposes.

## About
This lab covers host discovery, TCP port scanning, service/version detection, and
saving results with **Nmap**. I interpreted open and closed ports, identified the
services behind them, and assessed which exposures matter from a defensive point
of view.

**Topics:** `nmap` · `port-scanning` · `host-discovery` · `network-mapping` · `cybersecurity` · `ethical-hacking`
Through them I practiced:
- Host discovery, TCP port scanning, and service/version detection
- Packet capture, display filters, and protocol analysis
- Documenting findings with evidence and recommended responses

## Note
These are academic exercises, not production security assessments. Raw packet
captures are intentionally not published because they can contain personal
browsing data.
